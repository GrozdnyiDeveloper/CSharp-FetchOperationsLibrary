# Библиотека кастомных шагов обработки Fetch запросов
В данном репозитории представлена библиотека кастомных шагов по обработке Fetch запросов и вспомогательных операциях в системе Dynamics 365 CRM. 

Для представленных шагов реализован единый механизм обработки ошибок и логирования их работы с возможностью выбора типа (все операции, только не пустые, только ошибки, никакие) для каждого отдельного шага и записи Параметра. 

Представленные в библиотеке шаги делятся на 4 группы: Fetch, Conversion, Search и Common.

## Fetch - Содержит шаги по обработке Fetch запросов (сами Fetch запросы передаются при помощи записей сущности Параметр)
- AssignFetchXMLRecords - Назначает записи из Fetch запроса указанному пользователю
- BindUnbindFetchXMLRecords  - Производит привязку/отвязку записей из Fetch запроса к указанной в шаге записи
- ConcatFetchXMLData - Производит конкатенации значений указанного в шаге поля из записей Fetch запроса и возвращает итоговою строку
- DeleteFetchXMLRecords - Производит попытку удаления записей из Fetch запроса
- GetFetchXMLData - Получает данные записей из Fetch запроса (кол-во записей, GUID и значения первых четырёх полей из первой записи)
- RollupFetchXMLData - Производит агрегацию (тип указывается в шаге) значений указанного в шаге поля (дата или число) из записей Fetch запроса
- RunActionFetchXMLRecords - Производит запуск указанного действия для записей Fetch запроса с возможностью передачи параметров
- RunWorkflowFetchXMLRecords - Производит запуск указанного бизнес-процесса для записей Fetch запроса
- SetStateFetchXMLRecords - Производит попытку смены статуса для записей Fetch запроса в соответствии с указанным кодом
- UpdateFetchXMLRecords - Изменяет в записях Fetch запроса поля на указанные в нём значения
## Conversion - Содержит шаги по преобразованию входных значений в другие типы данных
- DecomposeDate - Производит разложение входной даты на её составные компоненты
- FormatDate  - Позволяет отформатировать входную дату в строку требуемого формата и региональной культуры
- ParseString - Преобразовывает входное строковое значение в требуемый формат на выбор (int, decimal, bool или DateTime)
- RegexMatch - Производит поиск во входной строке согласно заданному regex-выражению
- RegexReplace - Производит замену данных во входной строке согласно заданному regex-выражению
## Search - Содержит шаги по поиску определённых данных в системе
- FindSettingByKey - Производит поиск записи сущности Параметр согласно указанному ключу
- GetIdFromUrl  - Позволяет получить GUID записи из её динамичной ссылки
- GetWorkflowDependencies - Позволяет получить список зависимостей (действий и бизнес-процессов) для кастомного шага по его названию
## Common - Содержит прочие вспомогательные шаги 
- MathOperation - Позволяет производить базовые математические операции на переданными значениями
- RunActionByRecordId  - Производит запуск указанного действия для указанной записи с возможностью передачи параметров
- RunWorkflowByRecordId - Производит запуск указанного бизнес-процесса для указанной записи
- ShareRecord - Позволяет предоставить определённые доступы (read, write, delete, append, append to, assign, share) к конкретной записи для указанного пользователя
- UnshareRecord - Позволяет отозвать все доступы к конкретной записи для указанного пользователя
